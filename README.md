# Student Performance Management System

## Introduction

The Student Performance Management System is a simple Java
application designed to help teachers calculate and view
student performance.

The system allows the user to enter the names of students and
their marks for three subjects. It calculates the average mark,
assigns a grade and shows whether the student has passed or failed.

## Features

- Enter the number of students
- Enter student names
- Enter marks for three subjects
- Check that marks are between 0 and 100
- Calculate student average marks
- Assign grades
- Display PASS or FAIL
- Allow the user to run the system again

## Java Concepts Used

### 1. For Loop

The for loop is used to go through each student and each subject.

### 2. While Loop

The while loop is used to make sure that the marks entered are
between 0 and 100.

### 3. Ternary Statement

The ternary statement is used to determine whether a student has
passed or failed.

### 4. Do-While Loop

The do-while loop allows the user to use the system again after
finishing the first set of students.

## How the System Works

First, the user enters the number of students.

The user then enters each student's name and marks for three
subjects.

The system calculates the student's average and assigns a grade.

The system also determines whether the student has passed or
failed.

Finally, the user can choose whether to use the system again.
